# Design document

## Color palette
*A blue-black gradient (`#000000` → `#080A0F` → `#0B1120`) forms the background. `#2D3B4E` is the single chromatic atmosphere. `rgba(235,237,242,…)` is the universal white — vary alpha for text hierarchy, surfaces, borders.*

| Token               | Value                    | Notes                            |
| ------------------- | ------------------------ | -------------------------------- |
| **primary-black**   | `#000000`                | Pure black — anchor              |
| **secondary-black** | `#040404`                | Near-black bridge                |
| **accent-black**    | `#060606`                | Deep black                       |
| **Background**      | `#000000` → `#040404`   | Wide page gradient (2-color)     |
| **Atmosphere**      | `#2D3B4E`                | Chromatic spotlight              |
| **White**           | `rgba(235,237,242,<α>)`  | Vary α for text, surface, border |
